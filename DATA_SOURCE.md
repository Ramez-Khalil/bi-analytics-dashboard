The downloader pins the original source bytes rather than relying on an unversioned Kaggle copy. Raw sample data are not redistributed in this repository. The committed aggregate CSVs, metrics and charts are generated by our own analysis, not copied figures from the source notebook. IBM's original source data remain unchanged locally. No IBM implementation code is copied.

The original course report identified the Telco dataset but did not establish its exact file hash or split seed; therefore the new analysis is not asserted to reproduce that historical run. The source is a demonstration sample, not newly collected operational customer data. We do not know a reliable observation period or a future prediction horizon. In particular, this analysis must not be described as predicting next-month churn.

Customer IDs are used only for uniqueness validation, then excluded from modeling and all published results. No individual prediction table is produced. No student submission, grade, instructor comments or private identity data are included.
